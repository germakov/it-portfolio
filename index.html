🌿 EcoFlow — адаптивный лендинг экосервиса

EcoFlow — демонстрационный проект современного адаптивного лендинга для технологичного экосервиса. Сайт представляет концепцию цифрового сервиса, который помогает пользователям рационально расходовать ресурсы, управлять энергопотреблением и экономить. Проект разработан с использованием HTML, CSS и JavaScript без сторонних UI-фреймворков.
